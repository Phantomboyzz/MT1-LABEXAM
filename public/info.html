Vehicle Management System

Welcome to the Vehicle Management Web Application. This project maintains vehicle records and demonstrates the core capabilities of Node.js and Express.js.

Technology Stack

Node.js HTTP Module FS Module Express.js RESTful APIs

Architecture Overview

The application is modularized into two distinct server components:

  • Part A (HTTP Server): Runs on port 3000 using Node's core http and fs modules. Handles static file delivery, basic routing, and POST payload buffering without external frameworks.
  • Part B (Express REST API): Runs on port 4000 using express.js to provide complete CRUD endpoints (GET, POST, PUT, DELETE) with JSON request parsing and robust validation.

Server Endpoints

Server Method Endpoint Description
HTTP (3000) GET / HTML Welcome Page
HTTP (3000) GET /vehicles List all vehicle records (JSON)
HTTP (3000) GET /about Application Information
HTTP (3000) GET /info Static HTML page served via FS module
HTTP (3000) POST /add-vehicle Add a new vehicle record
Express (4000) GET /vehicles Retrieve all vehicle records
Express (4000) GET /vehicles/:id Retrieve specific vehicle by ID
Express (4000) POST /vehicles Create a new vehicle record
Express (4000) PUT /vehicles/:id Update an existing vehicle
Express (4000) DELETE /vehicles/:id Delete a vehicle record
